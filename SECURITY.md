# Security policy

SaveToA has not made a stable release yet. Security fixes currently target the
latest development version.

Please report vulnerabilities privately through GitHub Security Advisories on
`bionicman/savetoa`. Do not include real backup data or credentials unless the
maintainer explicitly requests a minimal encrypted reproducer.

Particularly sensitive areas include command execution, credential handling,
archive extraction, destination path validation, encryption, manifest parsing,
retention, and restore activation.
